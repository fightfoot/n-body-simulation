For the input.txt file, you can input bodies in this way:
0 0 0 #position of the body
0 0 0 #velocity of the body
0 0 0 #acceleration of the body
5.97237e24 #mass
Earth #name

When entering the info for the particle dont include the # or anything that follows them.
You can have any number of particles as long as they follow the example above. As long as
the simulation.py is in the same folder as particle.py and input.txt; the program should work.
